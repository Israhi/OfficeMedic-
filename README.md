# 🏥 OfficeMedic

**OfficeMedic** is an advanced, modern, and open-source desktop application designed to rescue your information from corrupted Microsoft Office files (Word, Excel, and PowerPoint).

If Microsoft Office tells you a file cannot be opened because there are problems with the contents, **OfficeMedic** can extract the pure XML data and reconstruct it, bypassing external corruption.

![OfficeMedic UI Placeholder](https://via.placeholder.com/800x450.png?text=OfficeMedic+UI+Preview)

## ✨ Features

- **Bruteforce Recovery:** Extracts raw text and data directly from the corrupted internal XML structure.
- **Support for Modern Formats:** Works flawlessly with `.docx`, `.xlsx`, and `.pptx` files.
- **Image Extraction:** Includes an additional tool to extract all embedded images and media from a corrupted file without opening it.
- **Privacy First:** 100% offline. Your sensitive documents never leave your computer.
- **Bilingual UI:** Instantly switch between English and Spanish.
- **Modern Design:** Built with WPF, featuring a beautiful dark/light mode UI and micro-animations.

## 🚀 Download & Installation

1. Go to the [Releases](../../releases) tab.
2. Download the latest `OfficeMedic_Setup_v1.0.exe`.
3. Run the installer and launch the app.
*(Note: Windows SmartScreen might show a warning since the installer is unsigned by an enterprise CA. You can safely click "More info" -> "Run anyway").*

## 🛠️ For Developers

OfficeMedic is built using **C#**, **.NET 8.0**, and **WPF**.

### Prerequisites
- Visual Studio 2022 (or Rider)
- .NET 8.0 Desktop Runtime
